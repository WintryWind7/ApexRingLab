# Deep MLP

## 实验目标
探索网络深度对预测性能的影响，对比不同深度的MLP架构

## 输入格式
8维 `[map1, map2, x1, y1, r1, dx2, dy2, r2]`
- map1, map2: One-Hot地图编码 (district=[1,0], tropic=[0,1])
- x1, y1, r1: Ring1归一化坐标
- dx2, dy2, r2: Ring2相对Ring1的坐标

## 实验记录

| 版本 | 最佳轮数 | 早停 | 场景1 Ring2误差 | 场景2 Ring3误差 | 半径误差 |
|------|---------|------|----------------|----------------|----------|
| MLP v1.0 | 174 | 20 | 1679.7 px | 461.0 px | 7.3 px |
| MLP v1.1 | 119 | 20 | 1702.3 px | 493.8 px | 6.1 px |

## 模型版本说明

### MLP v1.0
- 架构: FC(8→256) → ReLU → Dropout(0.1) → FC(256→128) → ReLU → Dropout(0.1) → FC(128→64) → ReLU → Dropout(0.1) → FC(64→32) → FC(32→3)
- 参数量: 45,635
- 损失函数: CircleLoss (α=2.0, β=1.0)
- 问题: 半径预测存在一定误差(7.3px)，未能完全学习到毒圈贴边收缩的几何约束

### MLP v1.1
- 架构: FC(8→512) → ReLU → Dropout(0.15) → FC(512→256) → ReLU → Dropout(0.15) → FC(256→256) → ReLU → Dropout(0.15) → FC(256→128) → ReLU → Dropout(0.15) → FC(128→128) → ReLU → Dropout(0.15) → FC(128→64) → ReLU → Dropout(0.15) → FC(64→32) → FC(32→3)
- 参数量: 261,571
- 损失函数: CircleLoss (α=2.0, β=1.0)
- 问题: 参数量增加5.7倍但性能未提升，反而圆心误差更大，说明任务已达深度瓶颈
