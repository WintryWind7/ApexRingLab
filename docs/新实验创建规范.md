# 新实验创建规范

## 核心原则

### 框架组件
- `model/base.py` - 模型基类
- `model/trainer.py` - 训练器（自动评估）
- `model/evaluator.py` - 评估器
- `model/dataset.py` - 数据集
- `model/loss.py` - 损失函数
- `model/predictor.py` - 预测器基类
- `model/comparator.py` - 对比工具
- `utils/model_inspector.py` - 模型检查工具

### 实验文件
```
experiments/your_experiment/
├── model.py          # 模型定义（继承框架基类）
├── predictor.py      # 预测器（继承 Predictor）
├── train.py          # 训练脚本（使用 Trainer）
├── dataset.py        # 可选：自定义数据处理
├── loss.py           # 可选：自定义损失函数
├── checkpoints/      # 自动生成：训练过程文件
│   └── YourModelName/  # 自动按模型类名分类
│       └── best_model.pth
└── visualizations/   # 自动生成：可视化结果
```

**扩展规则**：
- 框架有的组件：直接使用
- 框架没有的组件：在实验目录维护
- 禁止修改框架代码

**模型文件管理**：
- Trainer 自动在 `checkpoints/` 下创建以模型类名命名的子目录
- 例如：`MLPBaseline` 模型 → `checkpoints/MLPBaseline/best_model.pth`
- 一个实验目录可以包含多个模型变体（如 `MLPDeep` 和 `MLPVeryDeep`）
- 每个模型的训练产物自动隔离在各自的子目录中

## 训练脚本模板

```python
import sys
from pathlib import Path
sys.path.append(str(Path(__file__).parent.parent.parent))

import torch
import torch.optim as optim
from model import YourModel
from predictor import YourPredictor
from model.dataset import get_dataloader
from model.loss import get_loss_fn
from model.trainer import Trainer
from model.evaluator import Evaluator


def train():
    train_loader = get_dataloader("train", batch_size=32, shuffle=True)
    val_loader = get_dataloader("val", batch_size=32, shuffle=False)
    test_loader = get_dataloader("test", batch_size=32, shuffle=False)
    
    model = YourModel()
    loss_fn = get_loss_fn("mse")
    optimizer = optim.Adam(model.parameters(), lr=0.001)
    scheduler = optim.lr_scheduler.ReduceLROnPlateau(optimizer, mode='min', factor=0.5, patience=10)
    
    save_dir = Path(__file__).parent / "checkpoints"
    
    # 训练（自动评估）
    trainer = Trainer(
        model=model,
        train_loader=train_loader,
        val_loader=val_loader,
        loss_fn=loss_fn,
        optimizer=optimizer,
        scheduler=scheduler,
        save_dir=str(save_dir),
        early_stopping_patience=20,
        coordinate_mode="relative",
        use_onehot=True,
        predictor_class=YourPredictor,  # 自动评估
        test_loader=test_loader,
        auto_evaluate=True
    )
    
    trainer.train(num_epochs=100)
    
    # 可视化
    device = "cuda" if torch.cuda.is_available() else "cpu"
    predictor = YourPredictor(model, device)
    evaluator = Evaluator(predictor=predictor, device=device)
    vis_dir = Path(__file__).parent / "visualizations"
    evaluator.visualize_predictions(output_dir=str(vis_dir))


if __name__ == "__main__":
    train()
```

## 自动评估

Trainer 自动评估流程：
1. 训练完成后加载最佳模型
2. 在测试集上评估
3. 计算 10 个指标（归一化到 0-1）
4. 写入 pth 的 `test_metrics` 字段（顶层）
5. 打印结果

pth 文件结构：
```python
{
    "model_name": "...",
    "model_state_dict": {...},
    "epoch": 100,
    "optimizer_state_dict": {...},
    "metrics": {
        "best_val_loss": 0.003,
        "best_epoch": 100,
        "train_loss": 0.002,
        "val_loss": 0.003,
        "history": {...}
    },
    "test_metrics": {  # 顶层
        "evaluated_at": "2026-01-20 18:25:25",
        "test_dataset_version": "2026-01-15 01:18:58",
        "evaluation_duration_seconds": 0.31,
        "metrics": {
            "scenario_1_only_ring1": {...},
            "scenario_2_ring1_and_ring2": {...}
        }
    }
}
```

## 评估指标

10 个指标及单位：
- `center_distance`: 圆心距离误差（像素 px）
- `radius_error`: 半径误差（像素 px）
- `mse`, `mae`, `rmse`: 均方误差、平均绝对误差、均方根误差（归一化 0-1）
- `x_error`, `y_error`, `r_error`: 各维度误差（归一化 0-1）
- `angle_error`: 角度误差（归一化 0-1）
- `distance_error_ratio`: 距离误差比例（归一化 0-1）
