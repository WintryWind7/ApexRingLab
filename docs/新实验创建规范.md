# 新实验创建规范

本文档说明如何在现有框架下创建新的模型实验。

## 核心原则

### 1. 统一使用框架组件

**所有新实验必须使用 `model/` 目录下的框架组件**：
- `model/base.py` - 模型基类（`BaseModel`、`VectorModel`、`ImageModel`）
- `model/trainer.py` - 训练器（`Trainer`）
- `model/evaluator.py` - 评估器（`Evaluator`）
- `model/dataset.py` - 数据集（`RingDataset`、`get_dataloader`）
- `model/loss.py` - 损失函数（`get_loss_fn`）
- `model/predictor.py` - 预测器基类（`Predictor`）

### 2. 框架扩展规则

- **框架内有的组件**：直接使用
- **框架内没有的组件**：在**实验文件夹内**维护

**禁止**：
- 不使用框架组件，自己实现训练循环
- 不使用框架的 Evaluator，自己实现可视化
- 修改框架代码来适配单个实验

### 3. 实验必须维护的文件

| 文件 | 说明 | 要求 |
|------|------|------|
| `model.py` | 模型定义 | 必须继承框架基类 |
| `predictor.py` | 预测器 | 必须继承 `model.predictor.Predictor` |
| `train.py` | 训练脚本 | 必须使用框架 `Trainer` 和 `Evaluator` |

## 实验目录结构

```
experiments/your_experiment/
├── model.py          # 必须：模型定义
├── predictor.py      # 必须：预测器
├── train.py          # 必须：训练脚本
├── dataset.py        # 可选：仅当需要特殊数据处理时
├── loss.py           # 可选：仅当需要自定义损失函数时
├── checkpoints/      # 自动生成：模型检查点（标准目录名）
└── visualizations/   # 自动生成：可视化结果
```

**Checkpoint 目录命名规范**：
- **单阶段训练**：使用 `checkpoints/` 目录
- **多阶段训练**：
  - 推荐：使用同一个 `checkpoints/` 目录，不同文件名（如 `best_model_stage1.pth`、`best_model_stage2.pth`）
  - 或：使用不同目录（如 `checkpoints_stage1/`、`checkpoints_stage2/`），但需在实验文档中说明原因

## 标准训练脚本模板

```python
import sys
from pathlib import Path
sys.path.append(str(Path(__file__).parent.parent.parent))

import torch
import torch.optim as optim
from model import YourModel
from predictor import YourPredictor
from model.dataset import get_dataloader
from model.loss import get_loss_fn
from model.trainer import Trainer
from model.evaluator import Evaluator


def train_your_model():
    """训练你的模型"""
    # 数据
    train_loader = get_dataloader("train", batch_size=32, shuffle=True)
    val_loader = get_dataloader("val", batch_size=32, shuffle=False)
    test_loader = get_dataloader("test", batch_size=32, shuffle=False)
    
    # 模型
    model = YourModel()
    model.summary()
    
    # 训练配置
    loss_fn = get_loss_fn("mse")
    optimizer = optim.Adam(model.parameters(), lr=0.001)
    scheduler = optim.lr_scheduler.ReduceLROnPlateau(optimizer, mode='min', factor=0.5, patience=10)
    
    save_dir = Path(__file__).parent / "checkpoints"
    
    # 训练（自动评估）
    trainer = Trainer(
        model=model,
        train_loader=train_loader,
        val_loader=val_loader,
        loss_fn=loss_fn,
        optimizer=optimizer,
        scheduler=scheduler,
        save_dir=str(save_dir),
        early_stopping_patience=20,
        verbose=True,
        coordinate_mode="relative",
        use_onehot=True,
        predictor_class=YourPredictor,  # 自动评估
        test_loader=test_loader,         # 自动评估
        auto_evaluate=True               # 自动评估
    )
    
    trainer.train(num_epochs=100)
    
    # 可视化（评估已自动完成）
    device = "cuda" if torch.cuda.is_available() else "cpu"
    predictor = YourPredictor(model, device)
    evaluator = Evaluator(predictor=predictor, device=device)
    
    vis_dir = Path(__file__).parent / "visualizations"
    evaluator.visualize_predictions(output_dir=str(vis_dir))


if __name__ == "__main__":
    train_your_model()
```

**关键点**：
- 必须传入 `predictor_class`、`test_loader`、`auto_evaluate=True` 启用自动评估
- 训练完成后自动评估并保存结果到 pth
- 可视化仍需手动调用

## 输入输出格式规范

### 模型输入
```
(batch_size, 8) - [map1, map2, x1, y1, r1, dx2, dy2, r2]
```
- `map1, map2`: One-Hot地图编码
- `x1, y1, r1`: Ring1的绝对坐标（归一化到 0-1）
- `dx2, dy2, r2`: Ring2相对Ring1的坐标

### 模型输出
```
(batch_size, 3) - [dx, dy, r]
```
相对坐标，需要在 Predictor 中转换为绝对坐标。

## Baseline 对比

使用独立的对比工具 `model/comparator.py` 对比多个模型：

```python
from model.comparator import compare_models

compare_models([
    "experiments/mlp_baseline/checkpoints/best_model.pth",
    "experiments/mlp_deep/checkpoints/best_model.pth",
    "experiments/your_experiment/checkpoints/best_model.pth"
], model_names=["Baseline", "Deep", "YourModel"])
```

对比工具会从 pth 文件读取 `test_metrics` 并展示对比结果。

## 检查清单

- [ ] 模型继承了框架基类

- [ ] 训练脚本使用了 `Trainer` 和 `Evaluator`
- [ ] 训练脚本传入了 `predictor_class`、`test_loader`、`auto_evaluate=True`
- [ ] 训练脚本最后调用了 `evaluator.visualize_predictions()`
- [ ] 如果使用自定义组件（dataset/loss），在实验目录维护
- [ ] 没有修改框架代码（`model/` 目录）
- [ ] Checkpoint 目录命名符合规范
