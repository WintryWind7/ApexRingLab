# 实验记录

## mlp_baseline
基线模型，使用One-Hot地图编码的简单MLP
- 输入: 8维 `[map1, map2, x1, y1, r1, dx2, dy2, r2]`
  - map1, map2: One-Hot地图编码 (district=[1,0], tropic=[0,1])
  - x1, y1, r1: Ring1归一化坐标
  - dx2, dy2, r2: Ring2相对Ring1的坐标
- 损失函数: MSE

## mlp_deep
探索网络深度影响，测试Deep_MLP架构
- 输入: 8维 `[map1, map2, x1, y1, r1, dx2, dy2, r2]` (同baseline)
- 损失函数: CircleLoss (alpha=2.0, beta=1.0)
