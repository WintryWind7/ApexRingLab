# 毒圈结构分析

## 分析目标

验证数据集中毒圈刷新的贴边趋势和正切/反切特征，为模型设计提供数据支持。

## 数据集信息

- 数据源：`data/use/full.json`
- 样本数：1865（排除 mp_rr_desertlands_hu）
- 贴边阈值：100 像素

## 贴边情况统计

### 整体贴边比例

| 层级 | 贴边数量 | 比例 |
|------|---------|------|
| Ring2 贴 Ring1 | 1618 | 86.8% |
| Ring3 贴 Ring2 | 1219 | 65.4% |

### 贴边组合分布

| 组合类型 | 数量 | 比例 |
|---------|------|------|
| 都贴边（Ring2 贴 Ring1 且 Ring3 贴 Ring2） | 1177 | 63.1% |
| 都不贴 | 205 | 11.0% |
| 只有 Ring2 贴 | 441 | 23.6% |
| 只有 Ring3 贴 | 42 | 2.3% |

### 条件概率

**当 Ring2 贴 Ring1 时，Ring3 也贴 Ring2 的概率：72.7%**

这说明贴边具有连续性，如果 Ring2 贴边，Ring3 也很可能贴边。

## Ring3 刷新方向分析

### 整体方向分布（所有样本）

| 指标 | 数值 |
|------|------|
| 平均角度 | 55.42° |
| 中位数 | 37.79° |
| 标准差 | 49.28° |
| 正切（0-90°） | 1429 个（76.6%） |
| 反切（90-180°） | 436 个（23.4%） |

**正切样本是反切样本的 3.28 倍**

### 详细角度分布

| 角度区间 | 数量 | 比例 |
|---------|------|------|
| 0-30° | 765 | 41.0% |
| 30-60° | 476 | 25.5% |
| 60-90° | 188 | 10.1% |
| 90-120° | 153 | 8.2% |
| 120-150° | 140 | 7.5% |
| 150-180° | 143 | 7.7% |

### Ring3 贴边时的方向分析

当 Ring3 贴 Ring2 边界时（1219 个样本）：

| 方向类型 | 数量 | 比例 |
|---------|------|------|
| 正切（0-90°） | 1131 | 92.8% |
| 反切（90-180°） | 88 | 7.2% |

**贴边时正切样本是反切样本的 12.85 倍**

角度统计：
- 平均值：34.83°
- 中位数：26.48°
- 标准差：32.78°

## 结论

1. **贴边趋势明显**：Ring2 有 86.8% 的概率贴 Ring1，Ring3 有 65.4% 的概率贴 Ring2
2. **贴边连续性**：当 Ring2 贴边时，Ring3 也贴边的概率高达 72.7%
3. **正切趋势显著**：Ring3 整体有 76.6% 的正切趋势，贴边时更是高达 92.8%
4. **方向集中**：41% 的样本角度在 0-30° 之间，说明正切方向非常集中

## 对模型设计的启示

1. **贴边特征**：应该将 Ring2 是否贴 Ring1 作为重要特征
2. **方向特征**：Ring1→Ring2 的方向向量对预测 Ring3 位置有重要意义
3. **条件建模**：可以考虑分别建模贴边和不贴边的情况
4. **角度约束**：可以考虑在损失函数中加入角度约束，鼓励模型学习正切趋势
