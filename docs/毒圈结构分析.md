# 毒圈结构分析

## 地图坐标系

所有地图使用统一的 16384×16384 坐标系。

## 毒圈规则

- Ring1、Ring2、Ring3 逐级刷新
- Ring2 必须完全包含在 Ring1 内
- Ring3 必须完全包含在 Ring2 内
- 约束条件：`distance(center_inner, center_outer) + r_inner <= r_outer`

## 毒圈概念

### 贴边

指内圈的边界紧贴着外圈的边界（相切或接近相切）。

**判定标准**：当内外圈圆心距离接近理论最大值时，认为发生贴边。
- 理论最大距离：`r_outer - r_inner`
- 贴边容忍度：约 100 像素

### 正切/反切

主要出现在 Ring3 及以后层级，描述毒圈的刷新方向趋势。

- **正切**：Ring3 沿着 Ring1→Ring2 的方向继续刷新（远离 Ring1 中心）
- **反切**：Ring3 反向刷新（朝向 Ring1 中心）

**角度定义**：
- 方向向量1：Ring1 → Ring2
- 方向向量2：Ring2 → Ring3
- 夹角 0-90°：正切（方向一致）
- 夹角 90-180°：反切（方向相反）

**注意**：正切和反切是指刷新的方向趋势，而非绝对的停靠位置。

## 数据集统计

**数据源**：`data/use/full.json`（经过贪婪最近邻排序的完整数据集，按地图分组）

### 贴边趋势

| 层级 | 贴边比例 |
|------|---------|
| Ring2 贴 Ring1 | 86.8% |
| Ring3 贴 Ring2 | 65.4% |

**贴边组合分布**：

| 组合类型 | 比例 |
|---------|------|
| 都贴边（Ring2 贴 Ring1 且 Ring3 贴 Ring2） | 63.1% |
| 都不贴 | 11.0% |
| 只有 Ring2 贴 | 23.6% |
| 只有 Ring3 贴 | 2.3% |

**条件概率**：当 Ring2 贴 Ring1 时，Ring3 也贴 Ring2 的概率为 **72.7%**

这说明贴边具有连续性。

### 正切/反切趋势

**整体分布**（所有样本）：

| 方向类型 | 比例 |
|---------|------|
| 正切（0-90°） | 76.6% |
| 反切（90-180°） | 23.4% |

正切样本是反切样本的 **3.28 倍**。

**角度分布**：

| 角度区间 | 比例 |
|---------|------|
| 0-30° | 41.0% |
| 30-60° | 25.5% |
| 60-90° | 10.1% |
| 90-120° | 8.2% |
| 120-150° | 7.5% |
| 150-180° | 7.7% |

**贴边时的方向分析**（Ring3 贴 Ring2 时）：

| 方向类型 | 比例 |
|---------|------|
| 正切（0-90°） | 92.8% |
| 反切（90-180°） | 7.2% |

贴边时正切样本是反切样本的 **12.85 倍**，正切趋势更加显著。

角度统计：
- 平均值：34.83°
- 中位数：26.48°
- 标准差：32.78°

## 数据集版本

- **完整数据集**：`data/use/full.json`（经过贪婪最近邻排序，按地图分组）
- **训练使用**：`train.json`、`val.json`、`test.json`（从 full.json 随机分割）
- **分割比例**：70% / 15% / 15%

## 关键洞察

1. **贴边趋势明显**：Ring2 有 86.8% 的概率贴 Ring1，Ring3 有 65.4% 的概率贴 Ring2
2. **贴边连续性**：当 Ring2 贴边时，Ring3 也贴边的概率高达 72.7%
3. **正切趋势显著**：Ring3 整体有 76.6% 的正切趋势，贴边时更是高达 92.8%
4. **方向集中**：41% 的样本角度在 0-30° 之间，说明正切方向非常集中

## 对模型设计的启示

1. **贴边特征**：可以将 Ring2 是否贴 Ring1 作为特征
2. **方向特征**：Ring1→Ring2 的方向向量对预测 Ring3 位置有重要意义
3. **条件建模**：可以考虑分别建模贴边和不贴边的情况
4. **角度约束**：可以在损失函数中加入角度约束，鼓励模型学习正切趋势
5. **概率分布**：由于存在输入噪声和多样性，模型应输出概率分布而非单点预测
