# 数据集样式

## 地图坐标系

默认所有地图大小都为相同的 16384×16384

## 毒圈规则

- Ring1、Ring2、Ring3 逐级刷新
- Ring2 必须整个包含在 Ring1 内
- Ring3 必须整个包含在 Ring2 内

## 毒圈概念

**贴边**：
- 指内圈的边界紧贴着外圈的边界（相切或接近相切）
- 大多数数据集有贴边刷新的趋势

**正切/反切**：
- 主要出现在 Ring3 及以后层级
- 由于贴边刷新趋势，Ring1 和 Ring2 的连线方向很可能就是 Ring3 的刷新方向
- **正切**：Ring3 沿着 Ring1→Ring2 的方向继续刷新（远离 Ring1 中心的方向）
- **反切**：Ring3 反向刷新（朝向 Ring1 中心的方向）
- 正切和反切是指刷新的方向趋势，而非绝对的停靠位置

**数据集统计**（基于 full.json，排除 desertlands）：
- Ring2 贴 Ring1：86.8%
- Ring3 贴 Ring2：65.4%
- 当 Ring2 贴 Ring1 时，Ring3 也贴 Ring2 的概率：72.7%
- Ring3 贴边时，正切比例：92.8%（反切仅 7.2%）
- Ring3 整体正切比例：76.6%（包含不贴边的情况）
- 贴边阈值：100 像素

## 半径规则

同地图的同级毒圈半径是相同，但数据集可能有异常情况（不足1%），实际操作时会移除这些异常数据。

**标准半径值**：

| 地图 | Ring1 | Ring2 | Ring3 |
|------|-------|-------|-------|
| mp_rr_district | 4930 | 2419 | 1488 |
| mp_rr_tropic | 4894 | 2407 | 1284 |

## 排除地图

mp_rr_desertlands_hu 因数据质量问题排除

## 数据格式

```json
{
  "map": "mp_rr_district",
  "rings": [
    {"x": 9024, "y": 8679, "r": 4930},
    {"x": 11498, "y": 8251, "r": 2419},
    {"x": 12218, "y": 7665, "r": 1488}
  ],
  "timestamp": "2026-01-14T18:48:18.042062"
}
```

## 数据集版本

数据集版本始终使用 `data/use/` 文件夹中的数据集，以 `full.json` 作为完整数据集（处理后、分割前）。
