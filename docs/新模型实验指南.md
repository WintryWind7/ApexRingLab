# 新模型实验指南

本文档说明如何在现有框架下创建新的模型实验。

## 框架设计原则

- **数据加载统一**：所有实验共用`model/dataset.py`
- **格式转换在模型内部**：不同架构的输入格式转换在模型的`forward`中处理
- **评估流程统一**：所有实验使用相同的`Trainer`和`Evaluator`

## 实验目录结构

```
experiments/your_experiment/
├── model.py          # 模型定义（必须）
├── predictor.py      # 预测器（必须）
├── train.py          # 训练脚本（必须）
├── checkpoints/      # 模型检查点（自动生成）
└── visualizations/   # 可视化结果（自动生成）
```

## 创建新实验的步骤

### 1. 创建模型类

**文件**: `experiments/your_experiment/model.py`

根据输入类型选择基类：
- **向量输入**（MLP、Transformer等）：继承`VectorModel`
- **图像输入**（CNN等）：继承`ImageModel`
- **其他**：继承`BaseModel`

#### 示例1：MLP模型

```python
import sys
from pathlib import Path
sys.path.append(str(Path(__file__).parent.parent.parent))

import torch
import torch.nn as nn
from model.base import VectorModel


class YourModel(VectorModel):
    """
    你的模型描述
    
    输入: 8维 (2维One-Hot + 6维坐标)
    输出: 3维 (dx, dy, r)
    """
    
    def __init__(self):
        super().__init__(input_dim=8, output_dim=3)
        
        # 定义网络结构
        self.fc1 = nn.Linear(8, 128)
        self.fc2 = nn.Linear(128, 64)
        self.fc3 = nn.Linear(64, 3)
        self.relu = nn.ReLU()
    
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        前向传播
        
        Args:
            x: (batch_size, 8) - [map1, map2, x1, y1, r1, dx2, dy2, r2]
        
        Returns:
            (batch_size, 3) - [dx, dy, r]
        """
        x = self.relu(self.fc1(x))
        x = self.relu(self.fc2(x))
        x = self.fc3(x)
        return x
```

#### 示例2：CNN模型（在模型内部转换格式）

```python
class CNNModel(VectorModel):
    """
    CNN模型 - 将坐标转换为图像后处理
    
    输入: 8维向量（与其他模型相同）
    内部: 转换为图像表示
    输出: 3维 (dx, dy, r)
    """
    
    def __init__(self, grid_size: int = 64):
        super().__init__(input_dim=8, output_dim=3)
        
        self.grid_size = grid_size
        
        # CNN分支
        self.cnn = nn.Sequential(
            nn.Conv2d(1, 32, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1),
            nn.ReLU(),
            nn.AdaptiveAvgPool2d(1)
        )
        
        # MLP分支
        self.mlp = nn.Sequential(
            nn.Linear(64 + 8, 64),
            nn.ReLU(),
            nn.Linear(64, 3)
        )
    
    def _coords_to_image(self, x: torch.Tensor, y: torch.Tensor, r: torch.Tensor) -> torch.Tensor:
        """
        将圆坐标转换为二值图像
        
        Args:
            x, y, r: (batch_size,) 归一化坐标和半径
        
        Returns:
            (batch_size, 1, grid_size, grid_size) 二值图像
        """
        batch_size = x.shape[0]
        device = x.device
        
        # 创建网格坐标
        grid_x = torch.linspace(0, 1, self.grid_size, device=device)
        grid_y = torch.linspace(0, 1, self.grid_size, device=device)
        grid_y, grid_x = torch.meshgrid(grid_y, grid_x, indexing='ij')
        
        # 扩展维度以匹配batch
        grid_x = grid_x.unsqueeze(0)  # (1, H, W)
        grid_y = grid_y.unsqueeze(0)
        
        # 计算每个像素到圆心的距离
        x = x.view(-1, 1, 1)  # (batch, 1, 1)
        y = y.view(-1, 1, 1)
        r = r.view(-1, 1, 1)
        
        dist = torch.sqrt((grid_x - x)**2 + (grid_y - y)**2)
        
        # 圆内为1，圆外为0
        image = (dist <= r).float().unsqueeze(1)  # (batch, 1, H, W)
        
        return image
    
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        前向传播
        
        Args:
            x: (batch_size, 8) - [map1, map2, x1, y1, r1, dx2, dy2, r2]
        
        Returns:
            (batch_size, 3) - [dx, dy, r]
        """
        # 提取坐标（这里以Ring1为例）
        x1, y1, r1 = x[:, 2], x[:, 3], x[:, 4]
        
        # 转换为图像
        ring1_img = self._coords_to_image(x1, y1, r1)
        
        # CNN提取特征
        cnn_features = self.cnn(ring1_img).squeeze(-1).squeeze(-1)  # (batch, 64)
        
        # 与原始向量拼接
        combined = torch.cat([cnn_features, x], dim=1)
        
        # MLP预测
        output = self.mlp(combined)
        
        return output
```

### 2. 创建Predictor

**文件**: `experiments/your_experiment/predictor.py`

```python
import sys
from pathlib import Path
sys.path.append(str(Path(__file__).parent.parent.parent))

import torch
from typing import Dict, Optional, Tuple
from model.predictor import Predictor


class YourPredictor(Predictor):
    """你的模型的预测器"""
    
    # 地图到One-Hot的映射
    MAP_TO_ONEHOT = {
        "mp_rr_district": [1.0, 0.0],
        "mp_rr_tropic": [0.0, 1.0]
    }
    
    def __init__(self, model, device: str = "cuda"):
        super().__init__(device)
        self.model = model.to(device)
        self.model.eval()
    
    def predict(self, map_name: str, ring1_data: Dict, ring2_data: Optional[Dict] = None) -> Tuple[Dict, Dict]:
        """
        预测Ring2和Ring3
        
        Args:
            map_name: 地图名称
            ring1_data: {"x": x1, "y": y1, "r": r1} (归一化坐标)
            ring2_data: Ring2数据（可选）
        
        Returns:
            (ring2_dict, ring3_dict): 绝对坐标
        """
        if map_name not in self.MAP_TO_ONEHOT:
            raise ValueError(f"未知地图: {map_name}")
        
        map_onehot = torch.tensor(self.MAP_TO_ONEHOT[map_name], dtype=torch.float32).to(self.device)
        x1, y1, r1 = ring1_data["x"], ring1_data["y"], ring1_data["r"]
        
        with torch.no_grad():
            if ring2_data is None:
                # 场景1：只给Ring1，预测Ring2和Ring3
                
                # 预测Ring2
                ring1 = torch.tensor([x1, y1, r1], dtype=torch.float32).to(self.device)
                input1 = torch.cat([map_onehot, ring1, torch.zeros(3).to(self.device)]).unsqueeze(0)
                output1 = self.model(input1).cpu().numpy()[0]
                
                dx2, dy2, r2 = output1[0], output1[1], output1[2]
                x2, y2 = x1 + dx2, y1 + dy2
                
                # 预测Ring3
                ring2_rel = torch.tensor([dx2, dy2, r2], dtype=torch.float32).to(self.device)
                input2 = torch.cat([map_onehot, ring1, ring2_rel]).unsqueeze(0)
                output2 = self.model(input2).cpu().numpy()[0]
                
                dx3, dy3, r3 = output2[0], output2[1], output2[2]
                x3, y3 = x2 + dx3, y2 + dy3
                
                return (
                    {"x": float(x2), "y": float(y2), "r": float(r2)},
                    {"x": float(x3), "y": float(y3), "r": float(r3)}
                )
            
            else:
                # 场景2：给Ring1+Ring2，预测Ring3
                x2, y2, r2 = ring2_data["x"], ring2_data["y"], ring2_data["r"]
                dx2, dy2 = x2 - x1, y2 - y1
                
                ring1 = torch.tensor([x1, y1, r1], dtype=torch.float32).to(self.device)
                ring2_rel = torch.tensor([dx2, dy2, r2], dtype=torch.float32).to(self.device)
                input2 = torch.cat([map_onehot, ring1, ring2_rel]).unsqueeze(0)
                output2 = self.model(input2).cpu().numpy()[0]
                
                dx3, dy3, r3 = output2[0], output2[1], output2[2]
                x3, y3 = x2 + dx3, y2 + dy3
                
                return (
                    {"x": float(x2), "y": float(y2), "r": float(r2)},
                    {"x": float(x3), "y": float(y3), "r": float(r3)}
                )
```

### 3. 创建训练脚本

**文件**: `experiments/your_experiment/train.py`

```python
import sys
from pathlib import Path
sys.path.append(str(Path(__file__).parent.parent.parent))

import torch
import torch.optim as optim
from model import YourModel
from predictor import YourPredictor
from model.dataset import get_dataloader
from model.loss import get_loss_fn
from model.trainer import Trainer
from model.evaluator import Evaluator


def train_your_model():
    """训练你的模型"""
    print(f"\n{'='*70}")
    print(f"你的模型实验")
    print(f"描述：...")
    print(f"{'='*70}\n")
    
    # 数据（使用框架的dataset）
    train_loader = get_dataloader("train", batch_size=32, shuffle=True)
    val_loader = get_dataloader("val", batch_size=32, shuffle=False)
    
    # 模型
    model = YourModel()
    model.summary()
    
    # 训练
    loss_fn = get_loss_fn("mse")
    optimizer = optim.Adam(model.parameters(), lr=0.001)
    scheduler = optim.lr_scheduler.ReduceLROnPlateau(optimizer, mode='min', factor=0.5, patience=10)
    
    save_dir = Path(__file__).parent / "checkpoints"
    
    trainer = Trainer(
        model=model,
        train_loader=train_loader,
        val_loader=val_loader,
        loss_fn=loss_fn,
        optimizer=optimizer,
        scheduler=scheduler,
        save_dir=str(save_dir),
        early_stopping_patience=20,
        verbose=True,
        coordinate_mode="relative",
        use_onehot=True
    )
    
    trainer.train(num_epochs=100)
    
    # 评估
    print("\n开始评估...")
    
    best_model_path = save_dir / "best_model.pth"
    model.load_checkpoint(str(best_model_path))
    print(f"已加载最佳模型: {best_model_path}")
    
    device = "cuda" if torch.cuda.is_available() else "cpu"
    predictor = YourPredictor(model, device)
    
    test_loader = get_dataloader("test", batch_size=32, shuffle=False)
    evaluator = Evaluator(predictor=predictor, device=device)  # 自动对比baseline
    metrics = evaluator.evaluate(test_loader)
    evaluator.print_metrics(metrics)
    
    # 可视化
    vis_dir = Path(__file__).parent / "visualizations"
    print(f"\n生成可视化...")
    evaluator.visualize_predictions(output_dir=str(vis_dir))
    
    print("\n实验完成！")
    print(f"  模型: {best_model_path}")
    print(f"  可视化: {vis_dir}")


if __name__ == "__main__":
    train_your_model()
```

## 关键点说明

### 1. 输入格式

所有模型接收相同的输入格式：
```
(batch_size, 8) - [map1, map2, x1, y1, r1, dx2, dy2, r2]
```

- `map1, map2`: One-Hot地图编码
- `x1, y1, r1`: Ring1的绝对坐标（归一化）
- `dx2, dy2, r2`: Ring2相对Ring1的坐标（相对坐标）

### 2. 输出格式

所有模型输出相同的格式：
```
(batch_size, 3) - [dx, dy, r]
```

相对坐标，需要在Predictor中转换为绝对坐标。

### 3. 格式转换在模型内部

如果需要不同的输入格式（如图像），在模型的`forward`方法中转换：

```python
def forward(self, x: torch.Tensor) -> torch.Tensor:
    # x: (batch, 8) 向量输入
    
    # 转换为你需要的格式
    transformed = self._transform(x)
    
    # 处理
    output = self.network(transformed)
    
    return output
```

### 4. 自动对比baseline

`Evaluator`默认会加载`experiments/mlp_baseline/checkpoints/best_model.pth`作为baseline对比。

如果不想对比（如baseline自己），设置：
```python
evaluator = Evaluator(predictor=predictor, device=device, baseline_model_path=None)
```

## 常见问题

### Q: 需要添加新特征怎么办？

A: 如果特征可以从现有数据计算，在模型内部处理。如果需要外部数据，创建自定义dataset。

### Q: 需要特殊的损失函数怎么办？

A: 在`model/loss.py`中添加新的损失函数类，或在实验目录创建`loss.py`。

### Q: 训练速度慢怎么办？

A: 
- 检查是否在模型内部做了耗时操作
- 考虑预计算并缓存
- 或在dataset中预处理

### Q: 如何调试模型？

A: 在`forward`中添加print或使用断点：
```python
def forward(self, x):
    print(f"Input shape: {x.shape}")
    x = self.layer1(x)
    print(f"After layer1: {x.shape}")
    ...
```
